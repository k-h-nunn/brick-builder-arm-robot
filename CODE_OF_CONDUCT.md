# Code of Conduct

This is a four-person team project for CS 6341 (Robotics) at UT Dallas. The expectations are
simple, and apply in pull requests, issues, and any other project discussion:

- Be respectful and direct. Critique the code and the idea, not the person.
- Assume good faith. If a pull request, review comment, or issue is unclear, ask — do not assume
  the worst reading of it.
- Keep project discussion in the project's own issues and pull requests, where the rest of the
  team and the eventual grader can see the reasoning behind a decision.
- If a conduct problem comes up that the team cannot resolve on its own, raise it with the course
  instructor.

This document is deliberately short. If the team ever needs a fuller policy, the
[Contributor Covenant](https://www.contributor-covenant.org/) is a reasonable starting point.
